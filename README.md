# Угадай пупсика 1-ой группы

Приложение на C++/Qt Widgets. Игрок по текстовой подсказке (и опциональной
подсказке-картинке) угадывает имя и отчество человека из 1-ой группы.

## Правила
- 10 раундов.
- Одна попытка на раунд.
- Правильный ответ без подсказки-картинки: +2 балла.
- Правильный ответ с подсказкой-картинкой: +1 балл.
- Неверный ответ: 0 баллов за раунд, переход к следующему.
- Ввод: `Имя Отчество` (регистр и `ё/е` не важны).

Требования: Qt 6.10+, CMake ≥ 3.21, C++17.

cmake --build build
